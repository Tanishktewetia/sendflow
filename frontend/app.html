How to get SMTP App Password:
  1. Go to your Google Account settings
  2. Enable 2-Step Verification (if not already enabled)
  3. Go to "App passwords" in Security section
  4. Select Mail and Windows Computer (or your device)
  5. Google will generate a 16-character app password
  6. Copy and paste it above

📖 Official Google Documentation

How to get Resend API Key:
  1. Sign up or log in to Resend.com
  2. Go to Dashboard → API Keys
  3. Click "Create API Key"
  4. Give it a name (e.g., "Java Mailer")
  5. Copy the generated key and paste it above
  6. Verify your domain in Resend settings

📖 Resend Official Documentation

How to get Outlook App Password:
  1. Go to account.microsoft.com
  2. Click "Security" from the left menu
  3. Enable "Two-step verification" (if not already enabled)
  4. Look for "App passwords" option
  5. Click on it and select Mail and Windows
  6. Microsoft will generate a 16-character app password
  7. Copy and paste it above

📖 Microsoft App Passwords Documentation
